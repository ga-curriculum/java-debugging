## About

Even the best programmers make mistakes when writing code. In computer programming, any mistake that causes the program to behave unexpectedly is called a **bug** or an **error**. Bugs can cause a program execution to:

- Run successfully but give undesired outputs (Logical errors)
- Abruptly stop and throw an error message (Runtime errors or Exceptions). 

**Debugging** is the process of identifying and resolving errors in a computer program to ensure it operates correctly. Manually reviewing the code to locate the root cause of the bug, especially in programs with kilo lines of code (1000 Lines of code = 1 1 Kilo line), is effort intensive and impractical. Thankfully, debugging is made easier by debugging features offered by the programming language and the IDE (Integrated Development Environment). In this module, we'll learn how to work with Java's and IntelliJ IDE's debugging features.
